# Segurança

O simulador é executado no navegador e não tem servidor próprio. Não envie senhas, tokens, gravações privadas ou dados pessoais em Issues e Pull Requests.

Para relatar uma vulnerabilidade com possível impacto, use o recurso privado de avisos de segurança do GitHub se estiver habilitado no repositório. Se não estiver disponível, contate o mantenedor por um canal privado indicado na página do projeto. Inclua passos para reproduzir e versões afetadas; aguarde uma correção antes de divulgar detalhes publicamente.

Não há dependências de terceiros no momento. A página usa APIs nativas do navegador para áudio, gravação e MIDI.
