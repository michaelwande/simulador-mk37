# Código de Conduta

Este projeto busca uma comunidade acolhedora e respeitosa. Participantes devem tratar todas as pessoas com respeito, aceitar críticas construtivas e priorizar o que é melhor para a comunidade.

Não são aceitos assédio, ataques pessoais, discriminação, intimidação ou publicação de informações privadas sem consentimento. Mantenedores podem editar ou remover contribuições que violem estas regras e limitar a participação de quem persistir na conduta inadequada.

Para relatar um problema, contate os mantenedores pelos canais privados disponibilizados na página do repositório. Evite publicar dados pessoais ou detalhes de vulnerabilidades em uma issue pública.
