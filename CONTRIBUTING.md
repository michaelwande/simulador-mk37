# Contribuindo

Obrigado pelo interesse em melhorar o Simulador SMK-37 Pro. O projeto é um protótipo estático; mantenha a execução sem dependências externas, a menos que uma mudança justifique claramente outra abordagem.

## Relatar problemas e sugerir melhorias

Use Issues para bugs, sugestões de funcionalidades ou melhorias na documentação. Inclua navegador/sistema, passos para reproduzir e o resultado esperado. Não anexe credenciais, gravações pessoais ou dados privados. Marque claramente qualquer comportamento que seja suposição e não evidência do firmware ou do aparelho.

## Fluxo de contribuição

1. Faça Fork do repositório.
2. Clone seu fork: `git clone <URL-DO-SEU-FORK>`.
3. Crie uma branch: `git switch -c tipo/resumo-da-mudanca`.
4. Faça uma alteração pequena e descreva-a em commits claros.
5. Envie a branch: `git push -u origin tipo/resumo-da-mudanca`.
6. Abra um Pull Request contra `main`, explicando motivação e como revisar.
7. Aguarde revisão e responda aos comentários; o mantenedor decide quando integrar.

Para documentação, indique a seção afetada. Para mudanças visuais, inclua capturas de tela se possível. Não prometa fidelidade ao firmware sem evidência verificável.

## Revisão

Como o projeto não tem build ou suíte de testes configurados, descreva as verificações manuais realizadas. Não inclua arquivos gerados, firmware proprietário ou materiais sem autorização de redistribuição.
